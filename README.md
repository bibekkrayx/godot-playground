# Game Development

A repository for learning game development with Godot. Contains course materials, tutorials, and small games built while exploring Godot fundamentals, GDScript, game mechanics, scenes, and assets.

## Projects

- **Foundations** – Learning basic Godot concepts and scripting.
- **Godot Essentials** – Exploring scenes, nodes, and game fundamentals.
- **Dice Catcher** – A small game built while learning game mechanics.
- **Tappy Plane** – A Flappy Bird-style game.
- **Course Docs** – Learning resources, assets, and course materials.

## Tech Stack

- Godot Engine 4
- GDScript

## Purpose

Learning, experimenting, and building small games to improve game development skills.
